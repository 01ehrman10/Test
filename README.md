# Calculateur Douane Véhicule

Estimation des droits et taxes d'importation d'un véhicule en zone UEMOA
(Côte d'Ivoire, Sénégal, Bénin, Togo). Page HTML autonome, sans dépendance :
ouvrir `index.html` dans un navigateur.

Les taux et limites d'âge sont indicatifs et doivent être vérifiés auprès des
douanes ou d'un transitaire agréé.
